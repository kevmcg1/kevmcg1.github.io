Make up a phrase, say what it should write, and from then on typing the phrase and pressing Enter gives you exactly that: a G-code line, several lines, or any text. For example my safe start can write G00 G18 G20 G40 G80 G99.

[ SYNTAX CHECK ]

Checks the program in the editor against Haas rules for the machine you picked. Sizes are shown in inches with millimetres in parentheses.

Fix all only applies fixes that do not invent a number. Anything needing your feed, speed, depth or clearance stays a suggestion. Alarm names come from published Haas lists and can differ by control and software version. Always prove out on the control before cutting.
